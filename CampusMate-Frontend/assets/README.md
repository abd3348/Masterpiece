# Assets

Place local media in the folder matching its type: `images/`, `icons/`, `fonts/`, `videos/`, or `models/`.

The existing fallback SVG images remain in `images/`. Other folders are reserved for future assets. Existing external images and Google Fonts keep their original URLs. Files selected by a user are previewed with temporary browser URLs; they are not written into these folders.
