# Campus Mate — Mockups & Wireframes

ملف Figma المقصود: https://www.figma.com/design/vRXeICzaoJTSDXJTxQ6F1b/masterpro

## الحالة الحالية

تم إنشاء 11 Mockup داخل صفحة `02 · Campus Mate — Mockups`، مع حجز إطارات بقية الشاشات. صفحة `03 · Campus Mate — Wireframes` تحتوي إطارات محجوزة لم تُبنَ بعد. توقفت الكتابة بسبب بلوغ حد استدعاءات Figma MCP في خطة Starter.

هذه الإضافة المحلية تكمل 40 Mockup و40 Wireframe في الملف نفسه. تشمل الصفحات العامة، الدخول والتسجيل، المستأجر والمالك والإدارة، تبويبات الإدارة، وحالتي نتيجة تحليل الفيديو وتعديل العرض الجزئي. Arrangements وAgreement للمستأجر مدمجان ضمن Rentals ولا يتكرران كصفحات مستقلة.

## التشغيل في Figma Desktop

1. افتح ملف masterpro الأصلي في تطبيق Figma للكمبيوتر.
2. من قائمة Figma اختر Plugins → Development → New plugin، ثم Figma Design وقالب Run once، واحفظ الإضافة في مجلد جديد.
3. انسخ `code.js` من هذه الحزمة بدل ملف `code.js` المولّد. احتفظ بملف `manifest.json` الذي أنشأه Figma كما هو، لأنه يحتوي معرّف الإضافة الخاص بك.
4. شغّل الإضافة الجديدة من Plugins → Development وأنت داخل ملف masterpro.

مرجع الإعداد: [وثائق Figma الرسمية](https://developers.figma.com/docs/plugins/manifest/).

تحتاج الخطين DM Sans وPlayfair Display متاحين في Figma. إذا كان خط مفقودًا، ستتوقف الإضافة وتعرض اسمه. الملفات لا تتصل بالشبكة ولا تحتاج API key.

## ماذا تفعل الإضافة؟

- تكمل الإطارات الفارغة المحجوزة فقط، وتحافظ على المحتوى الموجود.
- تعيد استخدام مكوّنات الأزرار والحقول والتنقل والإحصاءات الموجودة في الملف.
- تبني الـ Mockups كنصوص وطبقات ومكوّنات وصور محتوى منفصلة قابلة للتعديل.
- تبني الـ Wireframes بألوان رمادية، ومربعات وخطوط بديلة للمحتوى، وبدون أي image fills.
- تستخدم أيقونة النجمة المعتمدة للـ AI كمسارات SVG قابلة للتعديل، بدل رمز emoji.
- تتحقق من الخطوط وعدد الشاشات وغياب الصور من الويرفريم، ثم تفتح شاشة الإيجارات الموحّدة.
- تحذف إطار الالتقاط المؤقت `83:2` بعد الاستفادة من صوره؛ التصاميم القديمة الأصلية تبقى محفوظة.

يمكن تشغيلها مرة ثانية: ستتجاوز الإطارات المكتملة. إذا حصل خطأ خلال بناء شاشة، لا تحذف محتواها يدويًا قبل مراجعة السبب. فحص JavaScript نجح محليًا، لكن لم تُشغّل الإضافة داخل Figma ولم تُراجع الشاشات الباقية بصريًا بسبب حد الأداة؛ لذلك اكتمالها غير مؤكّد حتى تشغيلها ومراجعتها.

`state.json` يسجل قائمة الشاشات والإطارات ومعرّفات المكوّنات للاستكمال. `code.js` هو كود الإضافة الكامل.
