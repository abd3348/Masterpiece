# Campus Mate — Mockups + Prototype

الملف المطلوب: [Untitled في Figma](https://www.figma.com/design/AIZ6AGq0gXUfHv2PD5mhZz/Untitled).

هذه إضافة محلية جاهزة للتشغيل في **Figma Desktop**. تبني 40 شاشة Mockup قابلة للتعديل وتربط أزرارها وتنقّلها كتجربة Prototype، باستخدام محتوى Campus Mate وألوانه وخطوطه وصوره المحلية. لم تُطبّق على ملف Figma بعد؛ أداة الحساب `abdallah` أوقفت القراءة والكتابة بسبب حد خطة Starter.

## التشغيل

1. فك ضغط `Campus-Mate-Interactive-Prototype.zip`.
2. افتح الملف المطلوب في تطبيق Figma Desktop، ثم اختر **Plugins → Development → New plugin**. اختر **Figma Design** ثم قالب **Run once** واحفظ الإضافة في مجلد جديد.
3. انسخ ملف **code.js** من الحزمة إلى مجلد الإضافة الجديدة، مكان `code.js` المولّد. **احتفظ بـ manifest.json الذي أنشأه Figma** لأنه يحتوي المعرّف الخاص بإضافتك. لا تحتاج أي تثبيت مكتبات أو API key.
4. شغّل الإضافة من **Plugins → Development → اسم الإضافة**. لا تغلق الملف أثناء الإنشاء. إذا طُلبت خطوط، أتح الخطين **DM Sans** و**Playfair Display** ثم أعد التشغيل قبل بدء الإنشاء.
5. بعد رسالة النجاح، افتح صفحة **Campus Mate · Interactive Mockups** واضغط **Present ▶**. ستجد أربع نقاط بداية: التصفح العام، المستأجر، المالك، الإدارة.

## ما الذي تنشئه؟

- صفحات عامة: الرئيسية، العقارات، تفاصيل العقار، السوق، عن المشروع، الدعم، FAQ، الخصوصية والشروط.
- تسجيل الدخول والتسجيل، مع اختيار حساب تجريبي للوصول إلى الأدوار الثلاثة.
- المستأجر: الرئيسية، التفضيلات، الزملاء، المفضلة، طلب الإيجار، الطلبات، الإيجارات والاتفاقية، الفحص، تأكيد الترتيب، الإيجارات الجزئية، الاجتماعات، الملف الشخصي، تقارير الحالة.
- المالك: العقارات، الطلبات، الترتيبات، إضافة عقار، الاجتماعات، الملف الشخصي وتقارير الحالة.
- الإدارة: النظرة العامة، المستخدمون، العقارات، البلاغات، التحليل، النشاط والملف الشخصي.
- حالتا نتيجة تحليل الفيديو وتعديل العرض.
- نوافذ خيارات للحقول مرتبطة بمتغيرات Prototype، نوافذ تأكيد الإجراءات، عرض الاجتماع، الأسئلة الشائعة ومساعد بإجابات جاهزة.
- مكوّنات مشتركة للأزرار والحقول والتنقّل والإحصاءات، ومتغيرات ألوان ومسافات وأنصاف أقطار.

## حدود التجربة والتحقق

هذا **Mockup تفاعلي**: الحقول تعرض خيارات بيانات تجريبية قابلة للاختيار. رفع الملفات، التحليل، المصادقة، الدفع والفيديو محاكاة. إجراءات الحفظ والموافقة والحذف تعرض حالات تأكيد توضيحية؛ ليست عمليات على بيانات المشروع أو الباك إند. اختيار قيمة حقل وتحديد checkbox يستخدمان متغيرات فعلية داخل الـPrototype.

نجح فحص JavaScript ومحاكاة محلية لـFigma API: 40 شاشة، 786 عنصر تحكم أساسي، 1545 ربط تفاعلي و198 نافذة. جميع الشاشات قابلة للوصول من نقطة البداية العامة، ولا توجد وجهة مفقودة ضمن المحاكاة. راجع `verification.json`.

**لم تُشغّل الإضافة داخل Figma ولم تُراجع النتيجة بصريًا** بسبب حد الأداة؛ الأرقام السابقة تحقق بنيوي محلي وليست تأكيدًا أن التصميم النهائي نُشر أو أن كل API قُبلت في Figma. يلزم تشغيل الإضافة ومراجعة Present لإتمام التحقق.

تضيف الإضافة صفحتي Mockups ومكوّنات، وتحافظ على الصفحات الأصلية. يجب أن يسمح الملف بإضافة هاتين الصفحتين. إعادة التشغيل بعد اكتمال البناء تفتح الناتج الموجود. عند فشل بناء جزئي، تتوقف وتحافظ عليه؛ لا تعيد التشغيل قبل مراجعة رسالة الخطأ والصفحة الناتجة.

## ملفات التطوير

`code.js` هو الملف الجاهز الذي تنسخه إلى إضافة Figma. الصور مضمّنة فيه، ولا يتصل بالشبكة. لا حاجة إلى الملفات الأخرى لتشغيله.

`runtime.js` يعرّف التفاعلات، و`build.cjs` يجمعه مع مولّد شاشات المشروع الحالي وصوره. `verify.cjs` يفحص البناء والروابط، وإمكانية الوصول إلى الشاشات، وعدم تكرار الناتج وعدم تغيير المحتوى الأصلي.

من جذر المشروع، باستخدام Node:

```powershell
node design/prototype-plugin/build.cjs
node --check design/prototype-plugin/code.js
node design/prototype-plugin/verify.cjs
```
