# مراجعة تصميم Campus Mate

شملت المراجعة جميع الصفحات الـ29، وتبويبات الإدارة الخمسة الإضافية، على عروض 360 و390 و768 و1440 بكسل. تمت مراجعة أعلى الصفحات وأسفل النماذج الطويلة، والقوائم المفتوحة والمساعد.

## المشاكل والإصلاحات

| المشكلة | مكانها | الإصلاح |
| --- | --- | --- |
| تكرار قائمة الحساب داخل المحتوى، وتأخر ظهور المحتوى على الموبايل | صفحات الأدوار | قائمة واحدة في الترويسة، مع قائمة قابلة للفتح والإغلاق على الشاشات الصغيرة. |
| غياب الوصول للحجوزات وبعض تبويبات الإدارة من القائمة الرئيسية | المستأجر والإدارة | إكمال الروابط وتحديد الصفحة أو التبويب النشط. |
| اختلاف العرض والهوامش والمسافات وأحجام الأزرار | جميع الصفحات | تنسيق مشترك في `css/shared/layout.css`، وأزرار وحقول مناسبة للمس. |
| نموذج الدخول يأتي بعد عنوان تسويقي كبير، والمساعد يغطي الحقول | الدخول والتسجيل | إظهار النموذج مباشرة على الموبايل، وإخفاء المساعد في صفحات الدخول. |
| زر المساعد العائم يغطي أزرار الإرسال والعناصر قرب أسفل الشاشة | صفحات التطبيق | نقل زر المساعد إلى شريط الحساب؛ تفتح نافذته عند الطلب وتُغلق بمفتاح Escape. |
| تداخل الترويسة الثابتة مع شريط الحساب | الرئيسية العامة | حساب موضع الترويسة من ارتفاع شريط الحساب. |
| فلاتر غير متساوية وحقول طويلة مقصوصة | البحث والزملاء | شبكة فلاتر منظمة، وتوسيع خيارات الفرز الطويلة على الموبايل. |
| جداول تتجاوز مساحة البطاقة | الإدارة وحجوزات المالك | تمرير داخلي للجدول مع تنبيه واضح وإمكانية الوصول بلوحة المفاتيح. |
| لوحة قصيرة تتمدد بفراغ كبير بجانب سجل النشاط | لوحة الإدارة | محاذاة لوحات الشبكة من الأعلى. |
| تباين ضعيف لنص الرسائل، ورابط زملاء للمستأجر يظهر للمالك | المحادثات | تحسين الألوان والمحاذاة، واستبدال رابط المالك بمراجعة الطلبات. |
| تكرار إحصائيات لوحة المالك قبل الطلبات والحجوزات | طلبات وحجوزات المالك | الاحتفاظ بالإحصائيات في لوحة المالك، وإظهار بيانات الصفحة مباشرة. |
| زر طلب الإيجار وقائمة الفحص يأتيان بعد محتوى طويل | تفاصيل العقار والفحص على الموبايل | تقديم ملخص الحجز وإجراء الطلب، وإظهار قائمة الفحص قبل المحتوى التوضيحي. |
| السعر بعيد عن زر إرسال طلب الإيجار | نموذج الطلب | إظهار المبلغ المطلوب بجوار الإرسال، وتحديثه مع المدة. |
| صور مكسورة عند تعذر الاتصال بمصدر الصور | بطاقات العقارات وصور المجتمع | رسومات SVG محلية بديلة، مع الإبقاء على الصور الأصلية عند توفرها. |

## إعادة الفحص

```text
node --test tests/api.test.cjs tests/http.test.cjs tests/structure.test.cjs
node tests/design-audit.cjs --after
node tests/browser-flow.cjs --file
node tests/browser-flow.cjs --api
```

يحفظ فحص التصميم الصور وقياسات الصفحات في [design-after](../tests/artifacts/design-after/report.json). يتحقق من عدم تجاوز عرض الشاشة، وحجم عناصر التحكم، والقوائم، والصور، ورسائل الأخطاء. صور المقارنة الأصلية محفوظة في `tests/artifacts/design-before/`.

أثناء الفحص تُحجب الخطوط والصور الخارجية عمدًا للتأكد من عمل الواجهة والصور البديلة دون اتصال بهذه المصادر؛ الصور البديلة توضيحية وليست صورًا حقيقية للعقارات.

نتائج التحقق: نجحت اختبارات المنطق والمسارات والـAPI وعددها 22، ونجح تدفق المتصفح مباشرة من الملفات وفحص عقد الـAPI التجريبي. يغطي تقرير التصميم 136 حالة عرض، دون تجاوز لعرض الصفحة أو صور مكسورة أو أخطاء JavaScript أو عناصر تحكم أصغر من الحد المعتمد في الفحص.
