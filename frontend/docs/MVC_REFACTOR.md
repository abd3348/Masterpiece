## التغييرات

- `CampusDb` أصبح `Data/AppDbContext.cs`، مع تحديث تسجيله واستخداماته في Controllers وServices.
- فصل الكيانات الـ23 من ملف واحد إلى ملفات داخل `Models`، ونقل `ScreenViewModel` إلى `ViewModels`.
- نقل إعداد الأعمدة إلى `Data/Configurations/EntityConfiguration.cs` وإعداد قيود SQL والفهارس والعلاقات إلى `SchemaConfiguration.cs`، وإزالة تكرار تعريف العلاقات والمفاتيح.
- إضافة Design-time ContextFactory وحزم EF Design/Tools وأداة dotnet-ef محلية مثبتة بالإصدار نفسه.
- إنشاء InitialCreate كاملة وSnapshot. اعتماد MasterDB الحالية بعد التحقق من مطابقة المخطط؛ إضافة سجل EF فقط. Migration ثانية لا تحتوي SQL وتثبت حفظ قيم bool الصريحة.
- إزالة SQL الخاص بإنشاء/تعديل الجداول أثناء بدء التشغيل. `DevelopmentDataSeeder` مسؤول عن بيانات العرض الاختيارية فقط. عند وجود Migrations معلقة يطلب التطبيق تطبيقها صراحة.
- نقل CSS وJS والصور إلى `backend/wwwroot` كمصدر وحيد، بدل ملفات مرتبطة من خارج المشروع. تحديث مولّد Razor ومصادر HTML والنسخة المستقلة والأدوات والاختبارات.
- static files تستخدم wwwroot مباشرة، و`/js/config.js` يأتي من MVC Controller. ملفات pages/seed/demo-showcase وconfig التجريبي لا تُخدم في تطبيق MVC ولا تدخل نسخة النشر.
- إزالة خاصية `EmptyBody` غير المستخدمة وملف JavaScript وصورة وprompt خاصة بالأنيميشن الملغى. نقل فيديو الاختبارات إلى `tests/fixtures/condition-walkthrough.mp4`؛ لا يُنشر مع الموقع. خُفّض محتوى الأصول السابقة بحوالي 5.54 MiB من ملفات JavaScript والصورة والفيديو.
- تنسيق C# وتبسيط README وتحديث تعليمات قاعدة البيانات.

لم تُحذف جداول أو سجلات تاريخية مثل RoommateContacts أو بيانات الاتفاقات المحفوظة. وجود واجهتها القديمة غير المستخدمة لا يثبت أن حذف بياناتها آمن؛ احتُفظ بعقد API وتغطية الاختبارات. مصادر HTML ونسخة العرض المستقلة بقيت لأنها تُستخدم فعلًا في التوليد والاختبارات.
