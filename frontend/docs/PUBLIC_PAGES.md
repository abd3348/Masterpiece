# الصفحات التعريفية والمساعدة

| الصفحة | محتواها | أماكن الوصول |
| --- | --- | --- |
| `html/public/about.html` | تعريف المنصة، أهدافها، وقسم الفريق | شريط البداية والتذييل |
| `html/public/support.html` | روابط مساعدة ونموذج دعم مع Regex | شريط الحساب وتذييل جميع الصفحات وAbout وFAQ |
| `html/public/faq.html` | ثمانية أسئلة وبحث وفتح الإجابات | التذييل وصفحة Support |
| `html/public/privacy.html` | شرح معالجة البيانات في النسخة التجريبية | التذييل ورابط Privacy Policy في التسجيل |
| `html/public/terms.html` | شرح استخدام النسخة التجريبية | التذييل ورابط Terms of Service في التسجيل |

لكل صفحة ملف CSS وJavaScript مطابقان لاسمها. التنسيق المشترك في `css/shared/information.css`، وتهيئة البحث والسنة في `js/shared/information.js`. الصفحات متاحة للزائر ولكل الأدوار دون تغيير صلاحيات صفحات الحسابات.

نموذج Support يعرض نتيجة التحقق فقط. لا يرسل بريدًا أو طلبًا للشبكة ولا يحفظ الرسالة. ربطه بخدمة دعم حقيقية يحتاج إلى مسار Backend لاحقًا؛ لم يُضف مسار غير منفذ إلى عقد API الحالي.

قسم الفريق يحمل المسمى الذي اختاره صاحب المشروع: **المالك والمطور**. صورته الأصلية من الملف الذي قدمه محفوظة في `assets/images/team-owner.jpg`، وتظهر مباشرة من HTML دون توليدها عبر JavaScript.
