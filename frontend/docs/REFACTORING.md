# تنظيم الكود والمحافظة على السلوك

أعيد تنظيم 29 صفحة دون تغيير تصميمها أو قواعد العمل. لكل صفحة ملف CSS وملف JavaScript مطابقان لاسمها داخل مجلد الدور. انظر [جدول الملفات](PAGE_FILES.md) و[دليل المشروع](PROJECT_STRUCTURE.md).

## التغييرات

- فصل صفحات البحث وتفاصيل العقار، وصفحات الزملاء والمفضلة والحجوزات، ومراحل طلب الإيجار إلى ملفات مستقلة.
- نقل CSS المشترك إلى `css/shared/` مع المحافظة على المتغيرات وترتيب القواعد والاستيراد ونقاط التجاوب والأنيميشن. ملفات CSS الصغيرة للصفحات تستورد القواعد المشتركة بدل نسخها.
- الإبقاء على السلوك المتشابه للرسائل والملف الشخصي وتقارير الحالة في `js/shared/`، مع ملف تشغيل واضح لكل صفحة. وظائف المالك المشتركة في `js/landlord/shared.js`.
- نقل قالب مساعد السكن الثابت إلى `index.html`، وهيكل صفحة الزملاء إلى قالب HTML داخل صفحتها. بطاقات العقارات والرسائل والتقارير تعتمد على بيانات وقت التشغيل، ولذلك بقي توليدها في JavaScript مع تهريب القيم المدخلة.
- تنسيق HTML وCSS وJavaScript بمسافات بادئة ثابتة، وتعليقات قصيرة للأقسام والمنطق الذي يحتاج تفسيرًا. حذف دوال التنقل الفارغة والاستيرادات غير المستخدمة.
- الإبقاء على طبقة JSON وAPI وRegex، وحالة الجلسة في الذاكرة، وعقود ASP.NET المستقبلية.

## التحقق

نجحت الاختبارات الآلية الـ25 وفحص المتصفح الكامل عند فتح المشروع من القرص وفحص وضع API باستخدام سيرفر اختبار محلي. تشمل الفحوص التسجيل والدخول لكل دور وRegex والبحث واختيار الزميل وتدفق الإيجار والرسائل والمساعد وإدارة العقارات وتقارير الحالة. أضيف فحص لنقطة التشغيل للتأكد من تحميل الملفات النسبية حتى عندما يحتوي وسم `<head>` على أسطر ومسافات نتيجة التنسيق.

حُفظت نسخة من المصادر قبل التعديل. جرى فحص تطابق بنية JavaScript قبل التنسيق وبعده، ثم فحص الواجهات على 136 حالة عرض: 29 صفحة وتبويبات الإدارة على مقاسات 360 و390 و768 و1440 بكسل. تطابقت قياسات العناصر الظاهرة وألوانها والخطوط والهوامش والحشو قبل التنظيم وبعده؛ تغيرت بعض أسماء الأصناف فقط لإخراج التنسيقات الثابتة من HTML.

صور وتقارير المقارنة في `tests/artifacts/refactor-before/` و`tests/artifacts/refactor-after/`. الفحص يوقف حركة الأنيميشن داخل متصفح الاختبار فقط للحصول على مقارنة ثابتة، ويحجب الصور والخطوط الخارجية لاختبار البدائل المحلية دون اختلاف الشبكة. تعريفات الأنيميشن ومراجع المكتبات الخارجية في التطبيق محفوظة.

## تنسيق التعديلات القادمة

إعداد التنسيق في `.prettierrc.json`، والملفات المولدة مستثناة في `.prettierignore`. Prettier أداة تطوير اختيارية؛ لا يحتاج التطبيق إلى تثبيته أو إلى Node لتشغيله. لا تعدّل `js/pages.js` و`js/seed.js` يدويًا، بل عدّل المصدر ثم أعد توليدهما بالأدوات الموجودة.
