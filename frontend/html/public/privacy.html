Privacy in this preview

How the current frontend handles your demo information.

Temporary demo data

Account details, rental requests, conversations, and other demo changes stay in browser page memory. This application does not use LocalStorage or SessionStorage. Refreshing the demo resets these changes.

Photos and videos

Files you choose in demo mode are previewed through temporary browser URLs. They are not uploaded by the demo. In connected API mode, upload and account requests go to the configured backend.

External content

Google Maps, external images, and web fonts load from their respective providers. Opening an external link takes you to that provider's website.

Future connected service

Before a real service launches, its operator will need to publish the details of how backend data is handled. This page describes the current project preview.
